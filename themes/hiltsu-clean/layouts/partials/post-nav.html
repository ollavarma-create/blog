{{- /* Previous / Next post navigation. Hugo's default sort order for sections is date-descending (newest first), which means: .PrevInSection points to the page above current → the newer one .NextInSection points to the page below current → the older one Most readers expect "Previous" to mean "older" and "Next" to mean "newer" (chronological reading order), so we deliberately swap the mapping. Renders nothing if both neighbours are missing (single-post sections). */ -}} {{- $older := .NextInSection -}} {{- $newer := .PrevInSection -}} {{- if or $older $newer }}
{{- with $older }} ← {{ i18n "previousPost" }} {{ .Title }} {{- else }} {{- end }} {{- with $newer }} {{ i18n "nextPost" }} → {{ .Title }} {{- else }} {{- end }}
{{- end -}}
